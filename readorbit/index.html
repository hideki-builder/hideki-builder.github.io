What it does

Your reading, connected.

Read

PDF zoom, Fit Width, Fit Page, page spreads, search, rotation, and selectable text. Local English/Japanese OCR makes scanned pages selectable too.

Organize

Explore domains, fields, and research topics with the Orbit Dock. Use cached or manual categories locally, or choose optional AI-assisted organization.

Understand

Select a passage to Translate, Explain, or Summarize using your configured AI provider. Check AI output against the original source.

Keep

Add your own comment to a quotation. Save notes as Markdown, including links back to the PDF location. You can choose a folder inside an Obsidian vault.

Getting started

Start with your documents.

These steps describe the current app workflow. They are preparation notes for when the Windows beta becomes available.

  1. Choose Local only to begin.Read PDFs, use local OCR, and save notes without enabling AI requests.
  2. Add a PDF.Use Add PDFs or drag a file into the window. In Local only mode it opens without AI analysis.
  3. Read and capture.Select a passage and choose Add Note. Pick your Markdown notes folder in Settings.
  4. Enable AI only if you want it.Choose BYOK and configure your own provider keys. Analysis and selection assistance send relevant text to the provider and may incur provider charges. Adding PDFs in BYOK mode can start analysis automatically. Review the privacy draft first.

Beta notice

Current limitations

  • The Windows beta has not been released. Packaging and support arrangements are still being prepared.
  • Local only mode keeps new documents Unclassified until you assign a category or run optional AI analysis.
  • OCR and automatic metadata can be incomplete. Local OCR currently includes English and Japanese language data.
  • Optional AI uses your own provider account and keys. ReadOrbit AI hosted account features are not available in production.
  • AI output and estimated API costs need independent verification. Your provider's billing statement is authoritative.
  • Closing a PDF does not erase its original file, notes, or caches. Notes links depend on the source PDF remaining available.
